# Guide To Punctuation in the Command Line

|Punctuation |Use in Command Line |
|----------- |-------------------|
|The dot / period: .|Periods in the the command line are used for accessing file extensions (.txt)|
|The Forward Slash: /|One of the most common uses for the forward slash is to navigate through the command line. Another of the main uses is to add comments in different pieces of code.|
|The tilde : ~ | You can think of the the Tilde as the location of your home. For example, typing cd ~, would bring you back to your home directory.|
|The hyphen / minus sign|The hyphen changes how differnet commands work in the command line. ls normally lists everything in a file. ls -a will also show hidden files. You can think of it as adding an option to an command. |
|Double quotes: ""|Double quotes are easy in that they allow you to add comments to your commands like in a git commit.|
